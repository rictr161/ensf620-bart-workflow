# Configuration

No general experimental reconstruction profile has been verified. The
[environment validation results](../docs/environment-validation-results.md)
record one owner-reported ARC script configuration for a particular acquired
3D CS input; the script values are not a generally validated profile or a
transcription of effective job settings. Do not infer sizes, axis meanings,
masks, trajectories or regularization settings for other inputs. Future
examples contain reviewed non-sensitive settings; input locations are
configured separately. Local paths and credentials must not be committed.
The synthetic procedure currently resides in `tests/synthetic_2d/README.md`.
